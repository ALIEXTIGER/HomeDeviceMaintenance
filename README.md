# HomeDeviceMaintenance - IPG203

أهلاً بكم في المستودع الرسمي المشترك الخاص بمشروعنا. تم تقسيم المهام برمجياً لضمان العمل المتوازي والسريع، ويرجى من كل زميل التوجه للمجلد الخاص به للبدء.

## تقسيم المهام والأدوار

* **الطالب 1 (منسق الفريق):**
  - تهيئة مستودع المشروع على موقع جيت هاب.
  - بناء فئة التحقق من البيانات والمصادقة لضمان الجودة.
  - تجميع المشروع ودمج الأكواد في ملف التشغيل الأساسي وتصحيح الأخطاء.
  - إعداد التقرير النهائي للمشروع ورسم مخطط العلاقات البرمجية.

* **الطالب 2 (برمجة البنية التأسيسية):**
  - بناء الواجهة البرمجية الأساسية للنظام.
  - بناء الفئة العامة الأب التي ترث منها الأجهزة.

* **الطالب 3 (برمجة منطق الأجهزة):**
  - بناء الفئات المشتقة للأجهزة المنزلية الثلاثة (الثلاجة، الغسالة، المكيف).
  - إعادة تعريف دوال حساب التكاليف الخاصة بكل جهاز حسب طبيعة عمله.

* **الطالب 4 (مراجعة جودة الكود وتنسيقه):**
  - مراجعة الملفات البرمجية وتنسيقها قبل عملية الدمج النهائي.
  - توحيد أسلوب التعليقات وهيكلية المجلدات في المشروع لتجنب الأخطاء.

* **الطالب 5 (برمجة الواجهة التفاعلية والأحداث):**
  - تصميم القوائم النصية التفاعلية المخصصة للمستخدم.
  - بناء نظام الإشعارات والأحداث عند تغيير حالة الصيانة.

## آلية العمل المشتركة

1. يرجى سحب نسخة من المشروع والبدء في الملفات المخصصة لكل دور بالتوازي.
2. بعد انتهاء كل طالب من جزئيته، يتم أرسال التعديلات والملفات للمنسق العام للمشروع لتجميعها ودمجها في الملف الرئيسي وإتمام التقرير والتسليم.

بالتوفيق للجميع!
